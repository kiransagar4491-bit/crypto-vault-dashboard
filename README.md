# CryptoVault — Crypto Dashboard

A modern, mobile-first crypto dashboard UI with dark glassmorphism theme, hover effects, and bottom tab navigation.

## ✨ Features

- **Home** — Market overview with 12 simulated coins, prices, 24h changes, sparklines, and trending coins
- **Watchlist** — Save/remove coins, add coins by symbol, synced across all tabs
- **Signals** — AI-powered Buy / Sell / Hold / **Sniper** signals with confidence scores
  - Filter by Type and Coin dropdown menus with hover effects
- **News** — Featured article + categorized headlines with filter chips
- **Chart** — Interactive SVG candlestick chart with coin selector and timeframes (1m–1d)
- **Bottom tab navigation** — Home / Watchlist / Signals / News with animated sliding indicator and hover lift effects
- **Live price simulation** — prices update every 4 seconds
- **Search overlay** — find any coin and add to watchlist

## 🛠️ Built With

- HTML5
- CSS3 (custom properties, glassmorphism, flexbox, grid, animations)
- Vanilla JavaScript (no frameworks, no build step)

## 🚀 Getting Started

1. Clone the repo:
   ```bash
   git clone https://github.com/kiransagar4491-bit/crypto-vault-dashboard.git
   cd crypto-vault-dashboard
   ```
2. Open `index.html` in your browser.

Or view the live site at: **https://kiransagar4491-bit.github.io/crypto-vault-dashboard/**
